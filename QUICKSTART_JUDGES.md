# ⚡ Quick Start for Judges

**Want to see CashLang in action? Here's the 2-minute evaluation guide.**

## 🌐 Option 1: Try Live Demo (Recommended)

👉 **[cashlang.vercel.app](https://cashlang.vercel.app)**

1. Click **"Templates"** button (top right)
2. Select **"NFT Minting"** template
3. Click **"Compile"** (green button)
4. See the magic:
   - ✅ Compilation in <500ms
   - ✅ Generated CashScript code
   - ✅ Simulation results
   - ✅ Contract artifact (JSON)
   - ✅ Bytecode size metrics

**That's it!** You've just compiled a Bitcoin Cash smart contract.

## 💻 Option 2: Run Locally

```bash
# Clone
git clone <repo-url>
cd cashlang

# Install (takes ~1 minute)
npm install

# Start dev server
npm run dev

# Open http://localhost:5173
```
