## Live Presentation Tips

### For Judges
1. **Start with the problem** - BCH dev experience pain points
2. **Show, don't tell** - Live demo is crucial
3. **Highlight innovation** - No equivalent exists for BCH
4. **Emphasize CashTokens** - Every template uses tokens
5. **Mention roadmap** - This is just v0.1

### Key Talking Points
- ✅ Lowers barrier to entry for BCH development
- ✅ Brings Ethereum/Solidity devs to BCH
- ✅ Production-ready output (real CashScript)
- ✅ Open source, MIT licensed
- ✅ Extensible architecture (CLI, VS Code extension coming)

### Demo Flow
1. Open live site (have it pre-loaded)
2. Show template gallery (30 seconds)
3. Load NFT template (most impressive)
4. Compile and show output (30 seconds)
5. Briefly show code architecture (if time)
6. End with roadmap slide

### Backup Plans
- Have screenshots ready if internet fails
- Have video recording as fallback
- Local dev server running on localhost
